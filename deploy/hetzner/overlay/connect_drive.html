محتاجين مفتاح جوجل مرة واحدة (Client ID + Secret). من غيرهم الزر مش هيشتغل.

  1. افتحي Google Cloud → Credentials
  2. Create credentials → OAuth client ID → Web application
  3. Authorized redirect URI:
  4. في Hugging Face Space → Settings → Variables and secrets، أضيفي:
    GOOGLE_OAUTH_CLIENT_ID
    GOOGLE_OAUTH_CLIENT_SECRET
  5. Restart للـ Space، وبعدين ارجعي للصفحة دي.

لو الـ Space اتعمل له rebuild، افتحي الصفحة دي تاني واربطي.
