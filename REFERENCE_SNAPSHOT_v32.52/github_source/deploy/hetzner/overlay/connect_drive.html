Google OAuth keys are needed once (Client ID + Secret). The button will not work without them.

  1. Open Google Cloud → Credentials
  2. Create credentials → OAuth client ID → Web application
  3. Authorized redirect URI:
  4. In Hugging Face Space → Settings → Variables and secrets, add:
    GOOGLE_OAUTH_CLIENT_ID
    GOOGLE_OAUTH_CLIENT_SECRET
  5. Restart the Space, then come back to this page.
